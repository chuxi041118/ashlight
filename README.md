Ashlight is a 2D arena survival game: pilot the last lantern-ship, guard the dying ember, and survive 10 waves of wisps, darters, spinners and brutes. Clear a wave, draft one of three upgrades that change how you fight, and hold the light until the final wave.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `game/index.html` from any static file server. No build step, no network requests.
